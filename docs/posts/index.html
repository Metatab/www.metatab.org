Metatab Metadata for the US Census

by eric | Dec 2, 2016 | Metatab | 0 Comments

The decennial US Census and the annual American Community Survey are the most important sources for demographic data in the US, and are the largest public datasets used to explore social issues. Each release of the ACS has 104 ZIP archives, each with 244 files, over a thousand columns, and millions of rows. Metatab and Metapack can help manage this complexity by providing structured metadata alongside the data itself.

Publish From Google Spreadsheets to CKAN

by eric | Nov 1, 2016 | Metatab | 0 Comments

Release 11 of the Metatab Add-On for Google Spreadsheets adds a significant new feature: publishing to CKAN. By creating a spreadsheet with both data and metadata, the Add-On can be the entire interface to a CKAN data package. Like the rest of the Add-On, this feature makes it easy for non-technical users to create and publish well-documented data packages.

Metatab Interface to datapackage.json

by eric | Oct 25, 2016 | Metatab | 0 Comments

One of the inspirations for Metatab was the Frictionless Data project, from Open Knowledge International, the creators of CKAN. The project's specification for data packages covers all of the common metadata for a dataset, and is extensible for less common needs. Metatab provides a human-friendly tabular interface to the same rich metadata model.
